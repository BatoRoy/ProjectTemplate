# Native port: component inventory (React → iced 0.14)

Source: `app-client/frontend/src` (frontend 0.4.1, ~9.2k lines). PoC: `native/poc-iced` (iced 0.14.0 / iced_widget 0.14.2, wgpu).
PoC Cargo features: `wgpu tiny-skia web-colors wayland thread-pool svg advanced`. **Not enabled**: `canvas` (lyon), `image`, `highlighter`, `markdown`, `qr_code`. No `.antialiasing(true)` on the application, so any `canvas` mesh would be aliased today.

Legend. **Status**: Done = in PoC at spec fidelity; Part = some of it exists; No = nothing. **Size** (one agent): S < ½ day, M ½–2 days, L 2–5 days, XL 1–3 weeks.
PoC building blocks referenced below: `Surface` (`widgets/surface.rs`, CSS box + button behaviour + 150 ms colour transitions, hover scale), `Label`/`Span` (`widgets/label.rs`, Blink line model, ellipsis, tabular, tracking, rich spans), `Icon`/`Ico` (`widgets/icon.rs`, lucide SVG, `.rotation() .spin() .filled()`), `Field` (`widgets/input.rs`, iced `text_input` + 4 px halo), `switch` (`widgets/switch.rs`), `modal` + `backdrop_blur` (`widgets/modal.rs`, `blur.rs`), `Scroller` (`widgets/scroller.rs`, vertical only), `grid`/`stretch_column` (`widgets/grid.rs`), `timer` (`widgets/timer.rs`), `ui.rs` helpers (`button` 5 variants × sm/md/icon, `badge` 5 tones, `card`, `card_box`, `kbd`, `hline/vline`, `app_mark`), `app.rs::segmented()` and `app.rs::rail_tip()` (iced `tooltip`), `style::Tokens` (`wash/tint/recessed/line_on`, easing fns).

Cross-cutting constraint from the PoC: translucent tokens (`text@.06`, `accent@.15` …) are **composited by the caller against a known opaque backdrop** (`over: Rgb` params in `ui.rs`). Every ported component must therefore know what it sits on (bg / card / surface / popover card). This is the main reason the kit needs a "backdrop" context (INF-1).

## 4. The hard ones

| # | Component | Realistic native approach | Main risk |
|---|---|---|---|
| 4.1 | **CodeEditor** (CodeMirror 6 + vim + 7 languages) | Build a custom widget on **cosmic-text's own editor stack** (`Editor` → `SyntaxEditor` with the `syntect` feature → `ViEditor` with the `vi` feature, via `modit`). This is what COSMIC Edit does, and the PoC already patches cosmic-text 0.15, so the FreeType hinting carries over. Draw: gutter (line numbers, active number in `subtext`), active-line band (`border@.35`), selection (`accent@.25`), caret (accent), vim status line; theme = the `cmTheme.ts` colour table mapped onto syntect scopes. Languages: syntect's default set covers JS, JSON, HTML, CSS, Python, Markdown; **TypeScript/TSX need extra `.sublime-syntax` files** (e.g. the `two-face` crate). Scrolling through `ScrollAxis` (INF-7). Fallback with less work: iced `text_editor` + `highlight_with` (custom syntect highlighter), no gutter or active line unless wrapped, no vim. | Scope creep (IME, undo grouping, wrap, search are all on us); syntect highlighting of large files is slow without incremental re-highlighting; vim parity with `@replit/codemirror-vim` is partial (`modit` covers the core motions only); text must stay on the Blink baseline model, so `Label`'s placement must be reused for editor lines. |
| 4.2 | **NodeGraph** (@xyflow/react) | One custom widget: model (nodes, edges, viewport {x, y, zoom}), `canvas` frames for the dotted background (gap 16, r 1, `border` colour), Bezier edges (xyflow default curvature) and the connection drag line; nodes drawn as `Surface` + `Label` **laid out at zoom × size** (re-layout per zoom instead of a scale transform, so text is re-rasterized crisp); handles as accent circles with hit-testing; interactions: node drag, background pan, wheel/pinch zoom around the cursor, handle-to-handle connect, fit view; Controls (+, −, fit, lock) as `Surface` buttons; MiniMap as a second canvas (node rects in accent, viewport mask `bg@.6`, pannable/zoomable).
